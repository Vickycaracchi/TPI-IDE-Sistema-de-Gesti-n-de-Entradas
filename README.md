## 🚀 Descripción del Proyecto

El **Sistema de Gestión de Entradas** es una solución integral diseñada para optimizar los procesos de administración, venta y validación de acceso a eventos. Combina una interfaz web para el acceso accesible de usuarios/clientes con un módulo nativo para tareas operativas o de administración directa.

---

## ✨ Funcionalidades Principales

El sistema está estructurado para cubrir el ciclo de vida completo de la entrada:

* 👥 **Administración y Gestión:**
  * Alta, baja y modificación de eventos, categorías y sectores.
  * Configuración de precios, aforo y ubicaciones disponibles.

* 🎟️ **Venta y Emisión:**
  * Proceso de compra y reserva de entradas para usuarios.
  * Generación de comprobantes o tickets digitales únicos.

* 🔍 **Control de Acceso y Verificación:**
  * Validación del estado de las entradas (Disponible, Reservada, Vendida, Utilizada).
  * Control de aforo en tiempo real.

## 🛠️ Arquitectura y Tecnologías

El desarrollo del proyecto se basa en la plataforma **.NET** e integración con servicios de Microsoft:

* **Lenguaje Principal:** C#
* **Ecosistema:** .NET (Soporte para soluciones Web y Nativas)
* **Base de Datos:** Microsoft SQL Server
* **Control de Versiones:** Git & GitHub
